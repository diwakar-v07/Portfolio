A fully interactive in-browser simulation workbench built directly into the web application:
1. **VLSI & Microarchitecture Explorer**: Inspect ALU vector engines, cache hierarchies, MMU translation lookaside buffers, and UART/SPI/I2C peripheral controllers with live gate counts, sub-nanosecond propagation latencies, and active power metrics.

## ⚡ Getting Started

### Prerequisites
- **Node.js**: v18.0 or newer
- **npm** or **yarn** / **pnpm**

### Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/diwakar-v07/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional for Contact Form):**
   Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
   Add your free **Web3Forms Access Key** (from [web3forms.com](https://web3forms.com)) to enable silent background email forwarding:
   ```env
   VITE_WEB3FORMS_ACCESS_KEY=your_free_access_key_here
   ```
   *(Note: If left empty, the contact form automatically provides a pre-filled direct mail client fallback so messages can always be sent).*

4. **Start Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

5. **Build for Production:**
   ```bash
   npm run build
   ```
